# AI Chatbot 🤖

A smart, personalized chatbot that can talk with you, remember your preferences, generate custom images, create text files, and answer general knowledge questions!

## ✨ Features
- **Smart Chatting**: Answers general knowledge questions (e.g., *"Who is Albert Einstein?"*).
- **Personal Memory**: Remembers your name and what you like across different sessions (e.g., *"My name is John"*).
- **Image Generation**: Creates custom images based on your prompts (e.g., *"Generate an image of a futuristic car"*).
- **File Creation**: Automatically writes and saves text reports for you (e.g., *"Create a report about black holes"*).

## 🚀 How to Run It

1. **Open your terminal** in this project folder.
2. **Install the required libraries**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Start the application**:
   ```bash
   python -m streamlit run app.py
   ```
4. A web browser will automatically open with your chatbot ready to use!
