# Global FX Platform

A production-grade, real-time foreign exchange analytics platform built with React, TypeScript, and Vite.

## Features

- **Real-time Currency Conversion**: Convert between any supported currencies instantly.
- **Trend Analytics**: Visual area charts showing historical performance (7D, 30D, 90D).
- **Confidence Meter**: Visual indicator of exchange rate confidence based on market volatility.
- **Offline Support**: Graceful degradation when the API is unavailable.
- **Modern UI**: Glassmorphism design with Framer Motion animations.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository (if applicable) or open the project folder.
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the development server:

```bash
npm run dev
```

This will launch the application at `http://localhost:5173` (by default).

### Building for Production

To build the application for deployment:

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.
